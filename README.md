# Етикети за аптека

Програма за печат на етикети с цени (код + цена) за аптека: Свободна продажба, НЗОК (с автоматично сваляне на реимбурсациите от nhif.bg), ръчно въвеждане и калибровка на листа стикери.

**Изтегляне:** https://velislav1.github.io/etiketi-apteka/

## Нова версия

1. Смени `APP_VERSION` в `main.py`.
2. Пусни `build.bat` → `dist\EtiketiApteka.zip`.
3. `gh release create vX.Y.Z dist\EtiketiApteka.zip --title "X.Y.Z"`

Инсталираните копия намират новата версия сами при следващото пускане.
