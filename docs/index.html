Етикети за аптека

Етикети с цени за Свободна продажба и НЗОК

⬇ Изтегли програмата
Windows 10 / 11 · не е нужен Python

Инсталиране на нов компютър

  1. Натисни „Изтегли програмата“ по-горе.
  2. Отвори изтегления EtiketiApteka.zip → десен бутон → Extract All… (Извлечи всички) → избери Desktop.
  3. В папката EtiketiApteka пусни EtiketiApteka.exe. За удобство: десен бутон → Send to → Desktop (create shortcut).
  4. Ако Windows покаже синьо прозорче „Windows protected your PC“ → More info → Run anyway. Това е само първия път.

Обновяване

Не е нужно да теглиш отново. При всяко пускане програмата проверява за нова версия и пита дали да се обнови. Настройките на етикетите и принтера се запазват.
